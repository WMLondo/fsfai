# @alejandrohn/create-fsfai

Thin wrapper to create a new [fsfai](https://github.com/WMLondo/fsfai#readme) project without a global install:

```sh
npm create @alejandrohn/fsfai
# or
pnpm create @alejandrohn/fsfai
```

It runs the `fsfai` CLI from [`@alejandrohn/fsfai`](https://www.npmjs.com/package/@alejandrohn/fsfai) at the same version, forwarding all arguments. See the [main README](https://github.com/WMLondo/fsfai#readme) for what it generates.
